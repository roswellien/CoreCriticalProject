Keep the game. Build its future.

The feel of a game lives in its rules: the way a machine moves, a weapon fires, or a mission unfolds. Core Critical’s goal is to preserve that original gameplay while building the platform support needed to keep it running.

MW3 is the current flagship, now in a closed playtest. The native runtime, Vulkan graphics, and the launcher and tools work together, each with its own testing.

Native Recompilation

Run the original game logic natively on modern Windows.

Vulkan Graphics

Draw the original game at modern resolutions, with optional lighting and upgrades.

Launcher & Tools

Install, update, configure and mod the game from one place.

One core. A growing project family.

Development starts with MW3 U.S. retail 1.2 on Windows x64. MW3: Pirate’s Moon and the MW4 titles—Vengeance, Black Knight, and Mercenaries—are future targets. They are part of the intended project family, with MW3 taking priority today.

AI-developed. Human-directed.

AI agents carry out research, code development, debugging, testing, and visual development under human direction. The project’s human maintainer sets its goals and priorities, reviews the results, and guides playtesting.

The aim is to run the original game logic natively and build modern platform support around it. AI-generated code and artwork are part of the development process; working features are demonstrated through actual execution, testing, and comparisons with the original game. Experimental results and offline visual previews are identified as such.

Faithful by default.

The native runtime preserves the original game logic rather than inventing new physics, AI, or mission rules. Modern platform services support that foundation, and every enhancement is optional and checked against the original presentation.

Progress is reported by what actually runs and what has been checked. The closed playtest is meaningful progress; full-game compatibility and a public release still require more work.

Questions & answers

Can I download and play it now?

Not yet for everyone. MW3 is in a closed, invite-only playtest while stability and performance improve. Applications are handled on our Discord, and approved testers receive the launcher with signed updates.

Will I need my own copy of the game?

Yes. Users supply their own legally obtained installation or media. Core Critical does not supply original executables, music, videos, or game assets.

Is Core Critical an official project?

Core Critical is an independent project. No affiliation or endorsement by the original games’ rights holders is implied.

What is MW3-RE?

MW3-RE is the native runtime Core Critical runs on. It builds on mw3-re by Owen Morgan, released under the MIT license, and the Core Critical fork keeps the upstream license and notices.

What is open source?

The project’s own code and research tooling are developed on GitHub. Original game content is separate, and generated game translations remain local under the project’s distribution policy. Third-party components retain their own licenses.

Are the website images gameplay screenshots?

Most are. The homepage comparison, Native Recompilation and Vulkan Graphics images are captures from Core Critical builds, and Launcher & Tools shows an earlier build of the launcher. The Mad Cat hangar artwork is illustrative, and no single image demonstrates every rendering feature.

Help bring it forward.

Explore the source, follow development, or contribute a reproducible observation. Useful reports describe the setup, what happened, and how to repeat it. Read the contribution guidance before submitting code or research, and keep original game files out of public reports.
