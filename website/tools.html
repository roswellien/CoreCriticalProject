Configuration, before the cockpit.

The current launcher supports the original-executable Vulkan wrapper track. A graphical interface and command-line mode bring resolution, aspect ratio, anti-aliasing, and texture filtering settings together for the prepared local development setup.

The launcher withdraws its window while the game runs and restores it afterward. This supports the original game’s fullscreen and focus behavior.

Read Vulkan Graphics for the rendering options behind these controls.

A separate space to experiment.

The documented workflow uses an isolated game profile, keeping the original installation’s files intact. It stages wrapper configuration and camera settings for a launch, backs up the registry values it changes, and restores those values when the game exits.

Local texture-bank switching is also part of the development workflow. Enhanced textures remain local experiments under the project’s content policy; this website does not offer a texture pack download.

A development tool, becoming easier to use.

Development snapshot · 13 October 2026

GUI and command-line launch are documented in the working local wrapper profile. The current setup requires prepared files and a fixed development checkout path.

Before a portable release.

The next work includes a repeatable setup procedure, more launch and restoration checks, configuration regression testing, and a complete third-party license and notice inventory. There is no general-purpose installer offered here yet.

Tools that support the whole project.

Core Critical also develops research and interoperability tooling for investigating original behavior and validating the native host. Contributors can help with reproducible reports, configuration checks, documentation, and focused improvements.

Start with the repository’s contribution guidance. Public contributions must leave original game files, private research inputs, and generated game translations out of the submission.
