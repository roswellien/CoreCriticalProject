Everything before the cockpit.

The Core Critical launcher sets up the game from your own MW3 installation and checks it before play. It keeps your resolution, window mode, antialiasing, texture filtering and view distance, and passes them to the game when you press Play.

Controls cover keyboard, mouse and controller profiles, with presets such as an MW5-style layout. Updates arrive signed through the launcher, and opt-in crash reports send redacted logs to help fix problems.

Choose your look.

Content packs add upgraded mechs, skins, environment textures, materials and music. Enable the ones you want, and the launcher checks that they fit together before the game loads them. Packs change how the game looks and sounds, not how it plays.

Build your own missions.

Mod Studio is an early, untested preview for map and mission authors. It offers terrain sculpting, time of day and weather, object placement, and mission and campaign building. Take the Mod Studio tour to see it.

Shipping to playtesters.

Playtest status · 27 November 2026

The launcher is installed and updated through the closed playtest. The current build is 1.0.61-preview, which added a setting for upscaled cutscenes.

Before a public release.

Clean installs, upgrades and rollbacks still need testing on more PCs. Mod Studio’s authored effects have not yet been checked in the game. Applications for the playtest are open on Discord.

Tools that support the whole project.

Core Critical also develops research, testing and benchmarking tools for checking behavior against the original game. Contributors can help with reproducible reports, configuration checks, documentation and focused improvements.

Start with the repository’s contribution guidance. Public contributions must leave original game files, private research inputs and generated game code out of the submission.
