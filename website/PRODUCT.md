# Core Critical website

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Plain HTML/CSS/JavaScript. Build and preview from this repository's `website/` directory. The site is hosted on Cloudflare Pages at `corecritical.dev` using the existing `core-critical` project; the maintainer is moving its source from the former website-only repository.

## Users

Players following development, players seeking installation guidance and releases when available, and developers or potential contributors.

## Product Purpose

Provide a public home for Core Critical at corecritical.dev. The primary visitor outcome at launch is to explore the projects and follow progress.

The homepage leads with Core Critical: MW3 as the current flagship and showcases the other projects below.

## Positioning

Core Critical encompasses the recompilation projects and supporting modernization efforts, including the Vulkan wrapper and launcher, with those efforts represented as equal parts of the project.

## Capabilities and Constraints

The project is hosted on GitHub. Cloudflare Pages serves the website. The site source and the published MechLab notes are maintained in this repository; Cloudflare's production connection is switched by the maintainer.

Website status and capability claims must reflect verified project evidence. Future targets must remain distinguishable from active implementation and publicly available releases.

The recomp project's distribution policy keeps original media and generated game code local. The website contains authored site files, licensed fonts, generated website illustrations, and links to already-published media; it does not include game files.

## Brand Commitments

The public brand is Core Critical. The domain is corecritical.dev. The user wants to avoid the MechWarrior name in project branding and has offered "Core Critical: MW3" as an example title treatment.

The website should feel like an official game website for the MW3 project. This is a presentation-quality reference, not a claim of publisher affiliation. mw5mercs.com and mw5clans.com are user-selected inspiration; do not duplicate either site. Develop an original Core Critical logo and website identity together. Palette, typography, artwork, and composition remain undecided.

The user selected homepage concept 3 and subsequently specified that the hero close-up must depict the Mad Cat / Timber Wolf from the original MW3 cover art. A generic fictional mech does not satisfy the brief. Preserve Core Critical's own branding and the selected page composition.

## Evidence on Hand

The repository README and project documentation contain development status and technical evidence. Those sources describe an experimental native host reaching live menu and Training, but no fully validated portable recompiled release. Public claims must be checked against current evidence before publication.

## Product Principles

- Serve players and contributors with accessible explanations and routes to deeper technical material.
- Make exploring the projects and following progress the primary launch experience.
- Give recompilation and other modernization efforts equal standing.
- Distinguish verified milestones, ongoing work, future targets, and available releases.
