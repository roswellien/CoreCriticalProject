// Mech3.exe 1.2

Core Critical on mw3-re

Core Critical would like to build its MechWarrior 3 remaster on a fork of mw3-re, and it would mean a lot to have mw3-re's blessing. mw3-re would provide the game; Core Critical would bring the modern presentation on top. This page sets out what that would mean, how mw3-re would be credited, and what would flow back upstream.

Core Critical is free and not sold. The aim is the best version of MW3 for the community.

// the split

Who brings what

mw3-reThe game: the full port of the original logic, its fixes and the --original switch, multiplayer, and Windows, Mac and Linux.
Core CriticalThe presentation and tooling: renderer, lighting, models, packs, editors, launcher and updates. All optional, and none of it changes gameplay.
// core critical layer

What Core Critical would add

Render layerA world-space renderer beside the Render3D seam, carrying models, materials and lights to the GPU. The original path stays untouched.
LightingSun, sky and haze; time of day authored for all 20 campaign missions; shadows; weapon lights and mech headlights.
Replacement mechsOptional and off by default. Built to keep the original part tree, pivots and firepoints, with original collision. Current models are ported from MW5 for private testing and are not published.
Packs and Mod StudioMech and skin packs, and a map and campaign editor that exports to mw3-re's mods folder.
LauncherInstall, settings, control presets, signed updates and crash reporting.
DisplayUltrawide output, FXAA and supersampling, anisotropic filtering.

How Core Critical runs today: a static recompile. The original Mech3.exe 1.2 code is machine-translated to 64-bit and runs inside a native host, which replaces DirectDraw and Direct3D with a Vulkan renderer. The enhancements above live in that host. On mw3-re they would sit beside the ported game instead of around translated code.

// upstream

What would flow back

  • Engine fixes as small pull requests, following mw3-re's conventions and tests, for upstream to take or leave. First candidates: automated Windows, Mac and Linux builds at every push (build checks only; the tests that need game files stay local), and ultrawide support (21:9 and 32:9 screens).
  • The high-res layer, available to upstream if it's ever wanted in the main port.
  • Open to other requests from upstream.
