The game you remember, carried forward.

Core Critical keeps MW3’s original rules in charge: missions, AI, movement, weapons and timing behave the way the game defines them. Around that logic, the project supplies what a modern PC expects, including graphics, windowing, input, controllers, audio and video.

The target is MW3 U.S. retail 1.2 on Windows x64, with Vulkan as the graphics backend. Players supply their own copy of the game.

One runtime at the core.

Since November 2026, the game runs on MW3-RE, a native port of the original game logic based on mw3-re by Owen Morgan (MIT license). Core Critical connects it to the project’s Vulkan renderer, the launcher’s saved settings, controllers, the original movies and the content packs a player enables.

The project began with a static recompilation of the original executable, which reached live menus, Training and Instant Action in October 2026. That host is no longer shipped. It remains a reference for comparing behavior with the original game.

In the hands of playtesters.

Playtest status · 27 November 2026

MW3-RE has been the only game runtime in the Core Critical installer since the 1.0.49 playtest build. Playtesters receive signed updates through the launcher; the current build is 1.0.61-preview. Recent releases streamed Campaign 1’s terrain height data, recovered from some video memory failures and fixed a zoom crash.

A closed playtest, not a finished release.

Longer sessions, the full campaign, save and load behavior, and a wider range of PCs and graphics cards still need testing. The playtest is invite-only while stability and performance improve.

Make every mission faithful.

  • StabilityFix the crashes and failures playtesters report, across longer sessions and more hardware.
  • Original-game comparisonsCheck physics, AI, timing, audio and scene rendering against the original game.
  • Campaign and modesWiden testing across the campaign, Instant Action and save/load behavior.
  • PerformanceKeep demanding scenes and longer view distances smooth on a range of PCs.
