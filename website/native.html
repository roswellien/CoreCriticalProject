The game you remember, carried forward.

Native recompilation translates the original game’s machine code into code that runs within a modern host. The project connects that logic to the graphics, windowing, input, audio, and other services it needs.

The target is faithful behavior: missions, AI, movement, weapons, and timing follow the original game’s rules. The first target is MW3 U.S. retail 1.2, with Windows x64 and Vulkan as the selected platform and graphics backend.

From startup to live Training.

Development snapshot · 13 October 2026

The experimental native host has executed an animated menu, rendered partial Training 1 scenes with the game HUD through Vulkan, and completed the normal Quit confirmation path. Startup and walking in interactive Training were observed.

An important step, with more to prove.

Full Training fidelity, whole-game compatibility, performance, and release readiness remain open. The development build depends on locally staged game images and generated output; it is not a portable release.

Make every step faithful.

  • Training behaviorCheck the remaining exercises, weapons, camera behavior, movement, and collision.
  • Original-game comparisonsValidate physics, AI, timing, audio, and scene rendering against the original.
  • Performance and compatibilityImprove demanding scenes and expand testing into campaign, Instant Action, and save/load behavior.
  • A reproducible buildWork toward a repeatable setup that uses the player’s own game data.
