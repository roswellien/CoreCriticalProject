# Playtest preview recovers from some video memory failures
Tags: Fix, Renderer, Playtest

Core Critical 1.0.58-preview is available to playtesters. If the renderer runs out of video memory while loading certain models or textures during a mission, it can now recover instead of ending the game.

## What changed

- The renderer frees unused resources and retries the allocation. If it still cannot find room, the model can temporarily disappear or the texture can draw plain while the renderer waits to retry. Tests forced these failures during a mission; the original playtester's memory pressure was not reproduced.
- The signed 1.0.58-preview release passed 830 native tests, a clean ISO install, and in-place upgrades from 1.0.57-preview and 1.0.52-preview through the first game frame.
- Earlier the same day, 1.0.57-preview shipped fixes for high-frame-rate mech movement and collisions. It also cleared the launcher's completed update notice after restart.
- The development branch now stores height and thickness maps as grayscale while still reading the older format. Focused renderer and tooling checks passed. It was not part of either signed preview; it has since been merged into the release branch, which does not by itself put it in a player build.

## What comes next

Check the memory recovery on machines that hit the problem in normal play, and test AI wall reversals at high frame rates in live missions.
