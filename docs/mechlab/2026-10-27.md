# Launcher 1.0.44, repeatable host builds, and better device support

Core Critical Launcher 1.0.44-preview is available for playtesters, with fixes for torso controls and original-game setup verification. We have also moved the native host into a repeatable repository build, received a successful build report from a second Windows PC, and merged further input improvements for a future release.

## Available for playtesters

- Launcher 1.0.44-preview adds Ctrl + numpad 0 to the MW5-style factory layout for the original torso-mode toggle. An untouched older factory preset gains the missing binding, while custom names, bindings, deliberately cleared controls, and the selected layout are preserved. Torso mode is saved independently of the keyboard layout; switching layouts does not reset it.
- Setup now distinguishes required original game files from optional texture and sound tiers. A supported retail installation is no longer rejected solely because those unused optional files are absent. Required original files still undergo verification.
- The signed launcher update and full installer are available through the playtest download site's Setup category. Existing players can use Check for updates in the launcher. Automatic checking remains optional, and downloading and installing remain the player's choice.
- The full installer retains MW3 native runtime 1.0.44. That runtime was not rebuilt for this launcher release. Existing settings, saves, content packs, and custom game paths were preserved in isolated upgrade tests, and update integrity, download-resume, installation, and rollback checks passed. Optional packs remain separate downloads.

## A repeatable native-host build

The maintained host source is now committed alongside a documented build command, dependency fingerprints, and file-level provenance. Contributors can compile the host directly without reconstructing a private patched folder, replaying an undocumented patch sequence, or obtaining the developer's translated object files.

The host build compiles seven objects and links against an existing locally available translated game DLL, which remains unchanged. The original supported MW3 installation and documented development tools are still required. This is a host-only build; generating the translated game code remains a separate process, and original game binaries and assets remain local.

A fresh-clone build verified all 163 host-source fingerprints, including nested dependencies previously missing from the source inventory. A contributor subsequently reproduced the build on a second Windows PC. That independent test also identified follow-up work around supported compiler versions and dependency header verification, so portability checks continue.

## Input improvements merged for the next release

A native startup fix now prevents force-feedback wheels and joysticks from selecting the unsupported legacy effects path. The device is reported without force-feedback capabilities so ordinary input can continue; force-feedback effects themselves remain unsupported.

Contributor testing with a Logitech G920 connected reached the main menu twice and exited normally. The shipped host stopped at the legacy force-feedback call on that same setup. Training and the complete installed-launcher path still need validation with the updated runtime.

Launcher-side joystick identification and selection controls have also merged into the integration branch. These newer input changes are not included in the published launcher 1.0.44 or native runtime 1.0.44; coordinated integration tests and a subsequent signed release are still needed.

## Remastered cinematics

We investigated the existing collection of 19 remastered MP4 cinematics and documented a staged native playback plan. The intended path combines modern decoding, synchronized audio, and full-resolution Vulkan presentation with the game's original movie events and pack-defined replacement mappings.

The current pack remains a launcher movie library. Native MP4 playback is not implemented yet. The first implementation milestone is complete opening-movie playback, correct skipping and cleanup, and a reliable return to the game menu before expanding validation to the full collection.

## Next checks

Continue independent build and input-device testing, resolve the portability findings, and validate the merged input changes through an installed launcher/runtime pair before publishing them. Cinematic implementation will proceed through focused pull requests. Each release will continue to distinguish available player features from experiments and work still awaiting integration.
