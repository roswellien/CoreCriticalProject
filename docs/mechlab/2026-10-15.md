# Pirate's Moon reaches a native menu; MW3 campaign progress

Work on MW3 paid off for Pirate's Moon: the expansion now boots to a native Vulkan menu, opens Options, returns, and quits normally. Reusing the existing runtime made this a same-day menu milestone. Missions and cinematics remain unverified. Earlier MW3 campaign progress and investigation notes are retained below as a rolling development record.

## Pirate's Moon: a working native menu build

- The experimental Windows x64 build displays the animated Pirate's Moon menu through the shared Vulkan renderer.
- A scripted run opens Options, returns to the main menu, accepts the quit confirmation, and exits with code zero after native dependency cleanup. It finishes after frame 210, before its 300-frame test limit.
- All 210 scene draw counts and fingerprints match a separate original-game reference using the same input and clock settings. Seven paired images are visually close, with mean RGB channel differences below 0.76 out of 255; they are not pixel-identical.
- The original game runs separately for comparison. The native build executes translated code and does not fall back to the original executable or an interpreter.

## Why this moved quickly

Pirate's Moon shares much of MW3's engine structure and Windows-era platform interfaces. The project could reuse its translation and compiler pipeline, native host, guest-memory contracts, Windows service adapters, input and timing infrastructure, and Vulkan renderer. The supplied C runtime is byte-identical to the MW3 runtime already handled by the project, so that difficult bootstrap work carried over directly.

The speed reflects the groundwork already done for MW3. Pirate's Moon still needed its own exact executable identity, addresses, library versions, callback tables and generated native dispatch. REA and Ghidra helped recover its startup and menu paths; missing initialization, interface and shutdown callbacks were then translated and checked through live execution. Similar engine structure provided a useful starting point, not permission to assume compatibility or copy MW3 addresses.

## What comes next for Pirate's Moon

The verified scope is a scripted native menu, Options round trip and normal quit. The run uses the game's original no-movie option, so it does not validate cinematics. Physical mouse and keyboard operation has not been manually checked, and no Pirate's Moon mission has been verified playable. Mission loading, gameplay, save/load behavior and broader compatibility remain future work.

The shared-runtime regression retained all 400 checked MW3 draw records and 41 saved frames. The existing 131-of-144 startup acceptance count is unchanged; these Pirate's Moon research results do not add formal acceptance credit. Game media, generated translations and native executables remain local, and this milestone is not a downloadable game release.

## Campaign entry and video startup

A timing-sensitive divide fault was traced to an optimized decoder calibration loop. The correction preserved the original measured loop rather than inventing a delay, clock value, or successful result.

Real-clock startup and video checks passed within their stated frame budgets. A separate automated campaign test reached first-mission gameplay, and the bounded original-compatible Training, GPU draw-stream, and Instant Action reference comparisons remained intact.

## User playtest

The user subsequently reported completing the first campaign mission in the local Remaster profile. That extends the earlier automated evidence, which covered mission entry and a bounded gameplay run. It is a user-confirmed playtest result, not independent proof of full-campaign or save/load equivalence.

## Issues still under investigation

- Status-panel backgrounds extend beyond their frames in the tested ultrawide setup, and the weapon-list container is wider than expected.
- Radar alignment, zoom-reticle tracking, and per-part enemy damage tint need comparison with original behavior.
- The intermission Mech Lab has substantial widescreen layout problems. Root-cause investigation and discussion are still required before its fix is chosen.

Other resolutions have not been user-tested for these reports. No fixes for the listed HUD and Mech Lab issues are claimed in this snapshot.
