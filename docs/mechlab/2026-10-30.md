# Website, crash reporting, and a new Atlas prototype

From October 28 through 30, we brought corecritical.dev into this repository and connected its updates to docs/mechlab/. Opt-in crash reporting now provides a hardware inventory and readable, redacted logs. We also prototyped a new mech asset-pack path and catalogued additional Pirate's Moon chassis for future work.

## What changed

- The live website source and Pages Function now live in this repository. The news pages build from public dated notes in docs/mechlab/, and the old cross-repository publishing bridge was retired. Production Pages builds from this repository's main branch.
- Launcher crash reports remain off by default. A player can enable automatic reporting or approve a one-time report after a failed session. Reports can include CPU and memory details, GPU and VRAM, graphics-driver metadata, settings and bounded, path-redacted log sections. The launcher now has a disclosure that explains what is sent and what is excluded.
- The website gained an administrator-only HTML archive for accepted reports. The route checks Cloudflare Access login before reading D1. The production archive schema still needs its migration and verification before the archive can be used; stored reports have no automatic expiry.
- A generic asset-pack workflow produced an Atlas prototype without per-mech runtime registration. A bounded hidden-window Instant Action run showed its actor render path; this did not establish complete Pirate's Moon gameplay, weapon fidelity, visible presentation or normal shutdown. A separate research inventory catalogued six candidate Pirate's Moon chassis and identified missing weapon and compatibility work.
- Launcher 1.0.45-preview was prepared with versioned installer and update filenames while retaining native runtime 1.0.44. Signing, installed setup and upgrade checks, and cloud publication remained before distribution.
- Contributor workflows added shared review and authoring guidance, issue-board checks, and checks focused on documentation-only changes.

## What comes next

Continue Atlas behavior and compatibility work, including weapons, visible presentation and normal shutdown.
