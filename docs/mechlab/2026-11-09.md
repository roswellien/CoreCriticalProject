# Mod Studio 1.0 and the MW3-RE source integration
Tags: Tools, Native
Image: studio/mod-studio-editor-v2.webp

In the days after the November 3 update, Core Critical shipped a standalone Mod Studio, corrected the previous launcher package, and brought the MW3-RE source and history into the Core Critical repository. It also laid out the renderer work needed to make MW3-RE the normal way to play.

## Mod Studio and the launcher

- Mod Studio 1.0 shipped on November 4 with a 2D tactical map and a 3D workspace. Map authors can sculpt terrain, set time of day and weather, place objects from the asset library, and build missions and campaigns. The standalone package finds its own project folders and can set up the bundled demo map without a development checkout. The authoring tools and previews give modders a workflow for building scenes. Wider in-game checks for the authored effects are still ahead.
- Launcher 1.0.47 and 1.0.48 shipped later on November 3. The second release fixed a missing startup dependency by packaging the complete runtime coordinator. Tests now exercise the installed package outside the development checkout. A crash report can reach the issue tracker when the optional archive save fails. Sending still follows the player's consent settings.
- The launcher now reports a conflict when two enabled environment packs claim the same region, including on a warm cache. Developers also adopted one command for routine local and CI checks, along with formatting hooks and clearer review checklists.

## Native runtime foundations

On November 9, Core Critical imported the upstream-based MW3-RE source with its history and updated the public site to credit the upstream project. The integration established a common source tree for the renderer and a roadmap for bringing back features players already used. An early Vulkan port added dynamic mech spotlights attached to model nodes, with cleanup when a limb or model disappears.

Work on the earlier native host reduced repeated heap lookups and added an opt-in render-thread path for development. Atlas development also corrected arm and forearm alignment and attached laser visuals to the firing donor muzzle while preserving the original hit endpoint and damage behavior. That work was checked in a local candidate.

## What comes next

The next step is to bring the launcher and game into the same installed workflow, then qualify the renderer and content features together in MW3-RE.
