# Same battle, new core: a matched arena comparison
Tags: Website, Renderer, Launcher

The Core Critical homepage now has a before-and-after slider that shows the same arena moment with stock visuals and with the upgraded packs and lighting. The signed launcher feed also moved to 1.0.59-preview. Separately, the team integrated a four-scene graphics benchmark and rendering changes whose playtest coverage is still being checked.

## What changed

- The homepage comparison holds the camera and mech poses fixed using the same replay tick. It shows how the upgrades look together, not how much performance any one change costs.
- The four-scene arena benchmark uses a repeatable camera and battle sequence. Two strict replays of the same build matched frame for frame on the tested setup. The launcher button can use the player's own graphics settings and active packs, and compares against that player's previous matching runs.
- The renderer added optional parallax mapping for surface depth and recalibrated low-light scenes: brighter SDR interiors and directional moonlight for outdoor night missions. Parallax was demonstrated with locally generated height maps; existing distributed packs do not yet show that effect.
- FastMenu now preserves the HD backdrop where supported. The main menu, Options and Controls were checked at 1920×1080. The separate in-mission Options clipping issue remains open.

## What comes next

Verify the benchmark from an installed launcher and bundled runtime, including first-run recording and reuse. Confirm compatible height-map packs and broader lighting coverage. The signed launcher feed and GitHub release notes are separate publication steps; the version in the feed alone does not verify which individual changes are in the player build.
