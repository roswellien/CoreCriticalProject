# Core Critical 1.0.60 and 1.0.61-preview: streamed height maps and upscaled cutscenes
Tags: Launcher, Renderer, Playtest

Core Critical 1.0.60-preview and 1.0.61-preview went out on the signed playtest update feed today. In 1.0.60-preview, the bundled MW3-RE runtime can now stream Campaign 1's terrain height maps for parallax depth instead of loading them all at once, and the launcher accepts packs built for that. Existing packs keep working unchanged. 1.0.61-preview adds a launcher setting for upscaled cutscenes.

## What changed

- The runtime loads full-resolution height maps only for the terrain cell the player is in and its neighbours, sharing them across frames within a 512 MiB cap. In a test run across Campaign 1's heaviest terrain transitions with High parallax, decoded height data peaked at 304 MiB.
- If the graphics card runs short of upload memory for a streamed map, that surface draws with its normal map only and tries again on a later frame instead of stopping the mission.
- When the launcher checks a pack's surface-material files, it now counts each decoded image at one byte per pixel, as the format's specification and reference readers do. Its memory limit and file checks are otherwise unchanged, so packs that loaded before still load.
- The runtime gained a developer-only option to play a high-definition intro cutscene in place of the original. It is off by default, nothing in the release turns it on, and no video is included.

## What changed in 1.0.61-preview

- The launcher's Graphics settings have a new Upscaled cutscenes option, on by default. When an enabled cinematics pack includes a checked high-definition intro clip, the launcher hands it to the runtime and the intro plays at the clip's own resolution instead of the original 640x480 video. Without such a pack, or with the option off, the original intro plays as before. No video is included in the update.
- Only the intro is covered for now. A damaged clip is noted in the launcher's log and skipped; another enabled pack's intro is used if it has one, otherwise the original plays. The original also plays if the runtime doesn't support high-definition movies or the clip's path contains non-ASCII characters, such as accented letters.
- The graphics benchmark loads faster: it remembers each environment pack's checksum between scenes instead of reading every pack again, unless the file has changed. In each of its four scenes, no two mechs share a chassis.

## What comes next

A streamed Campaign 1 height-map pack still has to be published before players see the deeper terrain; until then, existing packs look the same as before. The HD intro still needs a published pack before most players can use it, its sound sync still needs a listening check, and the other cutscenes are still to come.
