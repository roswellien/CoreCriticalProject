# Core Critical 1.0.60-preview: streamed height maps for Campaign 1
Tags: Launcher, Renderer, Playtest

Core Critical 1.0.60-preview is on the signed playtest update feed. The launcher and its bundled MW3-RE runtime can now stream Campaign 1's terrain height maps for parallax depth instead of loading them all at once, and the launcher counts their memory the same way the runtime does. Existing packs keep working unchanged.

## What changed

- The runtime loads full-resolution height maps only for the terrain cell the player is in and its neighbours, sharing them across frames within a 512 MiB cap. In a test run across Campaign 1's heaviest terrain transitions with High parallax, decoded height data peaked at 304 MiB.
- If the graphics card runs short of upload memory for a streamed map, that surface draws with its normal map only and tries again on a later frame instead of stopping the mission.
- The launcher now charges one byte per texel for surface height images in both pack format versions, matching the format contract and the runtime. Packs that already loaded still load.
- The runtime gained a developer-only option to play an upscaled intro cutscene in place of the original. It is off by default and nothing in the release turns it on.

## What comes next

A streamed Campaign 1 height-map pack still has to be published before players see the deeper terrain; until then, existing packs look the same as before. The HD intro needs a pack format and a launcher setting before it can be offered, and its sound sync still needs a listening check.
