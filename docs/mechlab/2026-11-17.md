# MW3-RE becomes the default Play path
Tags: Native, Launcher, Renderer
Image: launcher-dashboard.webp

From November 12–17, the MW3-RE v1.1.1 integration went from a launch preview to the default Play path for the upcoming 1.0.49 installer. The work connected saved settings, controllers, original movies, selected content packs, and the Core Critical Vulkan renderer to the same runtime.

## Launcher, content, and editor

- The new installer was prepared to ship MW3-RE as its sole bundled runtime. Play uses the saved windowed, fullscreen, or borderless mode. On the earlier host, a separate DXGI fix allowed VSync off in windowed mode when the display stack supports tearing. The renderer keeps its existing antialiasing and anisotropic-filtering controls. Windows font discovery was connected to the consolidated SDL host.
- Saved key bindings, joystick selection, and full controller profiles now reach the new runtime. Disconnecting a controller clears its latched throttle stop. Selected music packs reach the game, including FLAC and OGG through SDL3_sound. The original movies use a 32-bit helper with the player's verified game codec.
- The runtime can read pack files at and above 2 GiB. The launcher and Studio gained named modular profiles and native package validation and inspection. Enabled environment and mech packs supply matching textures, normal maps, and surface materials. Where matching pack data exists, the new runtime can also add water and cloud detail. The Windows staging recipe records the exact files that make up the runtime.
- The native editor now composes through the Core Vulkan device after game scaling and antialiasing. It borrows a bounded per-frame context and releases it when the editor closes. Work also connected approved HD HUD artwork and menu backgrounds to the new renderer.

## Lighting, fog, and gameplay presentation

Scenery can draw farther while the renderer keeps the authored gameplay camera range for targeting and simulation. Distant terrain and world detail, animated mechs, prepared-model fades and fog, and the sky's authored treatment received separate fixes. The GPU paths gained the stock weapon and fixture lights, configurable sun shadows, and authored mech headlights, with L as the default toggle. Damage tint on HUD portraits, laser brightness, and the green Mech Lab selection highlight were restored. Lens flares gained a choice of modern or original style.

The renderer can sample verified height data for eligible parallax materials on replacement models and the ground when the POM path is enabled. Wider material and live gameplay coverage remained open. The next update describes the later GPU menu switch, broader renderer stabilization, and the signed playtest.
