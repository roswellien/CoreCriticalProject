# The zoom crash fix reaches playtest preview

Core Critical 1.0.56-preview brings the MW3-RE zoom crash fix to the signed playtest update feed. The renderer also avoids repeated normal-map reads that could stall large missions and MechLab.

## What changed

- The runtime now skips drawing an empty zoom view before it can disturb the main view's projection. The zoom window keeps its minimum size at screen edges, and the HUD target marker uses the main view if the zoom view is empty for a frame.
- The Vulkan runtime suite passed. A controlled in-game test with dynamic lighting reproduced the crash before the change and kept running after it. That test forced an empty window; it did not replace a normal playtest at the screen edge.
- The renderer groups normal-map reads by page and reuses pages it has already uploaded. Bounded runs completed in two missions on an RX 9070, and a separate interactive MechLab check no longer hit the reported stall.
- Launcher reports now distinguish a hang from an unspecified exit and keep the exit code and runtime commit so the team can identify the build that was running.

## What comes next

Playtest the normal zoom transition at screen edges on more hardware. A separate launcher fix that clears a completed update notice after restart is in review and is not part of 1.0.56-preview.
