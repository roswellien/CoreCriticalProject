# Game targets

Only `mw3/` is an active implementation target. Pirate's Moon, MW4 Vengeance,
Black Knight, and Mercenaries are future targets; they have no implementation
or claimed support. Shared code should earn generalization through evidence.

The installed MW4 Mercenaries now has a [static assessment](../docs/mw4-reconnaissance.md)
and a [proposed recompilation execution plan](../docs/mw4-execution-plan.md).
Its protected game-code image must be resolved before native implementation.
